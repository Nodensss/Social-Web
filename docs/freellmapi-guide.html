🚀 FreeLLMAPI → Toyverse

Интерактивный гайд установки. Прогресс сохраняется в браузере.
1

Установить прокси FreeLLMAPI

▾

Что нужно заранее

  • Node.js 20+ — у тебя уже есть для Toyverse
  • Git для Windows
  • PowerShell или Windows Terminal

Клонировать репозиторий и установить зависимости

Открой PowerShell в C:\ и выполни:

git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
npm install

npm install займёт 1–2 минуты.

Создать .env и ключ шифрования

В той же папке freellmapi/:

Copy-Item .env.example .env
$key = node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
Add-Content .env "`nENCRYPTION_KEY=$key"
⚠ Сохрани этот ENCRYPTION_KEY где-нибудь вне репо (в менеджере паролей). Если потеряешь — все сохранённые ключи провайдеров станут нечитаемыми.

Запустить прокси

npm run dev

После запуска появятся:

  • API: http://localhost:3001/v1/chat/completions
  • Админка: http://localhost:5173
Если порт 3001 занят — в freellmapi/.env поставь PORT=3002.
2

Получить ключи у провайдеров

▾

Тебе не нужны все 14. Достаточно отметить ✅ хотя бы у 3 приоритетных (с оранжевой рамкой).

3

Залить ключи в админку прокси

▾

В админке http://localhost:5173

  1. Открой раздел Keys
  2. Для каждого полученного ключа: выбери провайдера → вставь ключ → Save
  3. В разделе Settings / Fallback задай порядок: Cerebras → Google → Groq → OpenRouter → Mistral
  4. В разделе API Key / Unified скопируй свой ключ вида freellmapi-...

Проверить работу прокси из терминала

Подставь свой ключ вместо freellmapi-твой-ключ:

$KEY = "freellmapi-твой-ключ"
$body = @{
  model = "auto"
  messages = @(@{ role = "user"; content = "Скажи привет по-русски одним предложением." })
} | ConvertTo-Json -Depth 5

curl http://localhost:3001/v1/chat/completions `
  -H "Authorization: Bearer $KEY" `
  -H "Content-Type: application/json" `
  -d $body

Должен вернуться JSON с русским ответом. Если ошибка — посмотри логи прокси.

4

Подключить к Toyverse

▾

Antigravity-версия (C:\Sofaweb\…\toyverse)

В lib/ollama.ts найди createOpenAI({…}) и замени:

const baseURL = process.env.LLM_BASE_URL || `${OLLAMA_URL}/v1`;
const apiKey  = process.env.LLM_API_KEY  || "ollama";
const openai = createOpenAI({ baseURL, apiKey });

В .env добавь:

LLM_BASE_URL=http://localhost:3001/v1
LLM_API_KEY=freellmapi-твой-ключ
OLLAMA_MODEL_PROFILE=google/gemini-2.5-flash
OLLAMA_MODEL_EVENT=cerebras/qwen-3-235b

Точные имена моделей подсмотри в админке прокси (раздел Models).

Перезапусти npm run dev. Готово.

Наш монорепо (Nodensss/Social-Web)

В корневом .env:

LLM_PROVIDER=openai
OPENAI_API_KEY=freellmapi-твой-ключ
OPENAI_BASE_URL=http://localhost:3001/v1
OPENAI_MODEL=google/gemini-2.5-flash
Если в packages/ai/src/providers/openai-llm.ts нет поддержки OPENAI_BASE_URL — попроси Claude добавить (1 правка).
5

Автозапуск как у Ollama (опционально)

▾

start-freellmapi.bat

Создай файл C:\freellmapi\start-freellmapi.bat:

@echo off
cd /d C:\freellmapi
if not exist logs mkdir logs
npm run dev > logs\proxy.log 2>&1

Положить в автозагрузку

  1. Win+R → shell:startup
  2. Создай ярлык на start-freellmapi.bat в этой папке
  3. Готово — после перезагрузки прокси поднимется автоматически
💡 По аналогии можно сделать автозапуск для Ollama, FreeLLMAPI и Toyverse — получится домашний сервер 24/7.
⚠

Подводные камни — обязательно прочитать

▾
Безопасность для детских данных. Прокси локальный, но запросы он шлёт в Google/Groq/Cohere. Они видят содержимое. Для имён игрушек и общих фантазий — ок. Для реальных имён детей, школ, дат рождения — лучше Ollama локально.
Free-tier меняется без предупреждения. Сегодня лимит 14k токенов/мин, завтра 6k. Поэтому fallback из 3–5 провайдеров — обязателен.
ToS провайдеров. Free-tier обычно запрещает коммерческое использование. Для семейного — ок, но почитай ToS каждого, на чьи токены полагаешься.
Bus factor = 1. У freellmapi 35 коммитов и один мейнтейнер. Если забросит — придётся форкать. Сохрани ENCRYPTION_KEY.

Прогресс сохраняется в localStorage этого браузера.
